# Guideline Cards Prototype

An interactive version of the lecturer guide for designing one educational chatbot conversation.
It belongs to a master thesis at the FHNW School of Business (MSc Business Information Systems):
"Conversation Design for Educational Chatbots: A Guideline-Based Conversation Design Framework
with Lecturer-Facing Guideline Cards for Higher Education".

The lecturer works through seven steps, uses 14 guideline cards and receives a conversation design
specification that can be copied as text. No chatbot is built and no technical knowledge is needed.

## Use

Open `index.html` in a browser. The page is one file and needs no installation and no account.
Entries stay in the browser of the person using it and are not sent anywhere.

## Status

Prototype. It supports the application of the framework and has not been evaluated yet.
The example in the tool is a constructed scenario, not a tested chatbot design.
